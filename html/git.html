Git

  • git status - Показывает состояние рабочего каталога и индекса.
  • git add - Добавляет содержимое рабочего каталога в индекс для последующего коммита.
  • git commit - Сохраняет снимок состояния проекта в истории коммитов.
  • git push - Отправляет локальные коммиты в удалённый репозиторий.
  • git log - Показывает историю коммитов в репозитории. Позволяет просматривать и фильтровать историю проекта, а также искать конкретные изменения.
